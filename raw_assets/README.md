# Raw Assets (`raw_assets/`)

This directory holds user-provided CC0 asset packs used by the Blender sprite baker and game audio/UI pipeline. The game gracefully falls back to procedural shapes/audio if any pack is absent.

Expected subdirectories:
- `quaternius_anims/` — Quaternius Universal Animation Library (`Universal Animation Library[Standard].zip`)
- `kaykit_anims/` — KayKit Character Animations (`KayKit_Character_Animations_1.1.zip`)
- `kenney_impact/` — Kenney Impact Sounds (`kenney_impact-sounds.zip`)
- `kenney_input/` — Kenney Input Prompts (`kenney_input-prompts_1.5.zip`)
